# 🏥 My Dyatel | Интеллектуальный медицинский портал поликлиники

Проект разработан по техническому заданию на основе **абстрактных классов (ООП)**, реляционной базы данных **SQLite**, технологий **HTML5/CSS3/JavaScript** с уникальным дизайном рабочих мест, **бело-красной медицинской цветовой гаммой**, **строго прямыми краями (0px border-radius)** и **разным расположением функций для личных кабинетов разных врачей и пациентов**.

## 📌 1. Архитектура ООП и Абстрактные классы (`backend/core/`)

Проект строго следует принципам Объектно-Ориентированного Программирования (наследование, абстракция, полиморфизм, инкапсуляция):

```
                     ┌───────────────────────┐
                     │   «abstract class»    │
                     │     AbstractUser      │
                     └───────────┬───────────┘
                                 │
           ┌─────────────────────┴─────────────────────┐
           │                                           │
┌──────────▼──────────┐                     ┌──────────▼──────────┐
│   «abstract class»  │                     │     PatientUser     │
│    AbstractDoctor   │                     │(Пациенты My Dyatel) │
└──────────┬──────────┘                     └─────────────────────┘
           │
 ┌─────────┼─────────────────────────┬─────────────────────────┬─────────────────────────┐
 │         │                         │                         │                         │
┌▼─────────▼────────┐     ┌──────────▼────────┐     ┌──────────▼────────┐     ┌──────────▼────────┐     ┌──────────▼────────┐
│  TherapistDoctor  │     │   SurgeonDoctor   │     │CardiologistDoctor │     │PediatricianDoctor │     │ ProctologistDoctor│
│(Д-р Елена Терапевт)│    │(Д-р Давид Хирург) │     │(Д-р Дима Кардиолог)│    │ (Д-р Анна Педиатр)│     │(Д-р Данил Воронько)│
└───────────────────┘     └───────────────────┘     └───────────────────┘     └───────────────────┘     └───────────────────┘
```

### Абстрактные классы:
1. **`AbstractUser(ABC)`**:
   - `@abstractmethod get_dashboard_summary()`: возвращает сводку KPI для конкретной роли.
   - `@abstractmethod get_permitted_actions()`: права и доступные операции в системе.
   - `@abstractmethod get_cabinet_layout_config()`: **динамическая компоновка интерфейса**, определяющая тему, расположение колонок и виджетов.
   - `@abstractmethod to_dict()`: сериализация данных для API.

2. **`AbstractDoctor(AbstractUser)`**:
   - Базовый абстрактный класс врача.
   - `@abstractmethod get_specialized_tools()`: уникальные инструменты специализации.
   - `@abstractmethod conduct_examination(patient_id, clinical_data)`: проведение профильного осмотра и формирование протокола.
   - `@abstractmethod get_specialized_stats()`: профильная клиническая аналитика.

3. **`AbstractMedicalRecord(ABC)`**:
   - Абстрактный класс записи электронной медкарты (ЭМК):
     - `TherapistRecord`: первичный осмотр + ЭЛН (больничный лист).
     - `SurgeonRecord`: протокол операции + состояние швов (шкала ASEPSIS).
     - `CardiologistRecord`: параметры ЭКГ + шкала риска SCORE-2.
     - `PediatricianRecord`: антропометрия ВОЗ + вакцинальный статус.
     - `ProctologistRecord`: HD-видеоаноскопия + стадия Goligher (I-IV) + малоинвазивное лечение.

## 🎨 2. Бело-красная цветовая гамма и строго прямые края

Интерфейс оформлен в соответствии с медицинскими стандартами:
- **Цветовая палитра**: Белый клинический фон (`#ffffff`, `#f8fafc`), высококонтрастный темный текст (`#0f172a`), акцентный медицинский красный (`#dc2626`, `#b91c1c`, `#fee2e2`), символизирующий скорую помощь, Красный Полумесяц и экстренную медицину.

## 📜 4. Автоматизация справок и выгрузка в PDF

В системе реализована автоматическая генерация и моментальный экспорт официальных медицинских справок с QR-кодами, штампами и подписями:
- **Форма 075/у (бывшая 086/у)**: Врачебное профессионально-консультативное заключение (для работы/учебы).
- **Форма 027/у**: Выписка из медицинской карты амбулаторного больного.
- **Форма 038/у**: Экспертиза временной нетрудоспособности.
- **Форма 095/у**: Справка о временной нетрудоспособности студента / учащегося.
- **Электронный больничный лист (ЭЛН)**: Интеграция с Enbek.kz, сроки нетрудоспособности, режим.
- **Экспорт в PDF**: Каждая справка открывается в модальном окне с кнопкой **«📥 Скачать в PDF / Печать»** и оформлена в официальном бланке Минздрава РК.

В системе открываются и полноценно функционируют **все кнопки**:
1. **Боковая навигация (Sidebar)**:
   - **«Рабочее место»**: возврат к основному дашборду текущего врача или пациента.
   - **«Кабинет колопроктолога»**: прямой переход в специализированный кабинет Д-ра Данила Воронько.
   - **«Расписание приемов»**: интерактивное окно с фильтрами по статусам (*Все, Подтвержденные, В ожидании, Завершенные, Отмененные*), поиском и отменой/завершением.
   - **«Медкарты (ЭМК)»**: единый реестр карт с фильтрами, историей болезни и выгрузкой протокола.
   - **«Рецепты и Аптека»**: реестр электронных рецептов с баркодами, статусами отпуска и прямой печатью.
   - **«Справки и ЭЛН (PDF)»**: централизованный реестр всех выписанных справок поликлиники с кнопками PDF-экспорта и выписки новой справки.
   - **«Аналитика & ЛИС»**: сводка клинических показателей, загрузка отделений и заказ анализов.
2. **Шапка (Header)**:
   - Демо-переключатели врачей и пациентов: Дима (Кардио), Давид (Хирург), Елена (Терапевт), Анна (Педиатр), Данил (Проктолог), Александр (Пациент).

   - **«+ Регистрация»**: раздельная регистрация пациентов и врачей с выбором специальности.
3. **Кнопка SOS 103**:
   - Экстренный диспетчерский экран с живым таймером прибытия бригады скорой помощи, GPS-координатами и отправкой медкарты.

## 💾 6. База данных SQLite (`damumed_portal.db`)

Реляционная база данных содержит 11 связанных таблиц:
1. `users`: идентификация (ИИН, пароль, ФИО, телефон, роль).
2. `doctor_profiles`: данные врача (лицензия, специализация, кабинет, стаж, категория, график).
3. `patient_profiles`: клинические данные пациента (дата рождения, группа крови, аллергии, хронические болезни, экстренный контакт).
4. `appointments`: электронные записи на прием с контролем занятости временных слотов.
5. `medical_records`: записи ЭМК с JSON-хранилищем специфических клинических параметров.
6. `prescriptions`: электронные рецепты с уникальными QR/штрих-кодами и сроком действия.
7. `sick_leaves`: официальные электронные больничные листы (ЭЛН) с номером и интеграцией Enbek.
8. `referrals`: электронные направления к узким специалистам и на инструментальную диагностику.
9. `vaccination_records`: национальный регистр иммунизации РК (серии вакцин, реакции, дозы).
10. `lab_orders`: заказы и валидированные результаты лабораторной информационной системы (ЛИС).
11. `certificates`: официальный регистр медицинских справок (075/у, 027/у, 038/у, 086/у, 095/у) с серийными номерами и PDF-экспортом.

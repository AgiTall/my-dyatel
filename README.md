# My Dyatel — медицинский портал

Локальная медицинская информационная система на **Python 3** (только стандартная библиотека), **SQLite** и **HTML/CSS/JS** без внешних зависимостей.

## Роли и возможности

- **Суперадминистратор (`superadmin`)**
  - Управление кабинетами, врачами и медсёстрами (создание, редактирование, удаление по отдельности).
  - Просмотр всех записей и пациентов, журнал действий (`audit_log`), резервное копирование БД и полная очистка базы с подтверждением.
  - Вход по умолчанию при пустой БД: ИИН `999999999999`, пароль `admin123` (или переменная окружения `PORTAL_ADMIN_PASSWORD`).
- **Врач (`doctor`)**
  - Цифровой кабинет: очередь пациентов слева, активный приём в центре (повод обращения, направитель, место оказания, диагноз, рецепты, направления), анализы и снимки справа.
  - Выдача справок (`075/у`, `026/у` и др.), больничных листов (ЭЛН), направлений, рецептов и направлений на анализы/рентген.
  - **Личная подпись (1:1)** в профиле или перед печатью документа; печатные формы с угловым штампом, круглой печатью клиники, личной SVG-печатью врача и QR-кодом локальной верификации (`/api/v2/verify?number=...`).
- **Медсестра (`nurse`)**
  - Привязана к конкретному врачу, работает с его очередью, оформляет данные обращения, направления и анализы.
- **Пациент (`patient`)**
  - Самостоятельная регистрация по ИИН, запись к врачам по их графику работы.
  - Личный кабинет: **Пакет ОСМС**, **Моя поликлиника**, **Мои данные** (медкарта, диагнозы, анализы, снимки, рецепты, направления, справки, больничные с печатью/PDF) и лента **Заказы**.

## Запуск

```bash
py -3 main.py
```

или на Windows через [run.bat](run.bat). После запуска откройте `http://127.0.0.1:8000`.

### Переменные окружения (опционально)

- `PORTAL_HOST` — адрес прослушивания (по умолчанию `127.0.0.1`)
- `PORTAL_PORT` — порт (по умолчанию `8000`)
- `PORTAL_ADMIN_PASSWORD` — пароль суперадмина при первом создании БД
- `PORTAL_SSL_CERT` / `PORTAL_SSL_KEY` — пути к TLS-сертификату и ключу для HTTPS

> **Примечание:** проверка документов по `/api/v2/verify` работает по локальному реестру портала и не заменяет государственную ЭЦП НУЦ РК или интеграцию с НЭПЗ.
